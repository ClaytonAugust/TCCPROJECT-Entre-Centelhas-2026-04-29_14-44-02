COMO USAR NA UNITY
1. Importe os PNGs para Assets/Art/UI.
2. Para cada PNG, selecione no Inspector:
   Texture Type = Sprite (2D and UI)
3. Na Image da UI, coloque a caixa_dialogo_marrom_1200x300.
4. Para texto, NÃO coloque o texto dentro do PNG.
   Use TextMeshPro por cima da caixa.
5. Para os botões, use os PNGs como Sprite no componente Image.
6. Para o hover:
   Normal = botao_normal
   Highlighted = botao_hover_selecao
   Pressed = botao_pressed
   Disabled = botao_desabilitado
7. O texto do botão deve ser TextMeshPro por cima do botão.
8. Se o projeto estiver em 1920x1080, uma boa configuração inicial é:
   - Caixa de diálogo: largura ~1700 px, altura ~260-300 px.
   - Texto: margem interna de 60-80 px.
   - Botões de escolha: largura ~1500-1600 px, altura ~70-85 px.
9. Mantenha o Canvas em Screen Space - Overlay para facilitar a montagem.

OBSERVAÇÃO
Os PNGs são elementos de interface independentes e foram feitos sem texto,
para que você possa reutilizar a mesma caixa e os mesmos botões em todos
os 5 cenários.
